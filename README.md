# Nick's Flooring Needs

Marketing site for Nick's Flooring Needs, an epoxy flooring service for people who find the business in local Facebook groups.

White and cobalt. Fraunces for headlines, Outfit for the rest. The quote form stays in the browser: it builds a short ticket the visitor can copy into a Facebook message or group post.

Stack: Next.js, TypeScript, Tailwind CSS, Framer Motion, shadcn/ui.

## Contact details

Phone, email, and a Facebook link are optional. Set them in `lib/site.ts`. Empty fields stay off the page.

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
```
